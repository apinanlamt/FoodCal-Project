# FoodCal

เว็บสำหรับเลือกรูปอาหารเพื่อจำแนกเมนู ประเมินแคลอรีและสารอาหาร และบันทึกประวัติอาหาร โดยไม่ต้องเข้าสู่ระบบ

## โครงสร้างโปรเจกต์

- `frontend/` — หน้าเว็บ HTML, CSS และ JavaScript
- `backend/` — FastAPI, ฐานข้อมูล และระบบประมวลผลภาพ
- `backend/model/` — โมเดล Food-101 และ THFOOD-50 พร้อมรายชื่อคลาสและข้อมูลโภชนาการ
- `database/` — ข้อมูลโภชนาการเริ่มต้น
- `data/foodcal.db` — ฐานข้อมูล SQLite ที่สร้างเมื่อเริ่ม backend; เก็บข้อมูลอาหารและประวัติทั้งหมดร่วมกัน

## ติดตั้งและเริ่มใช้งาน

ต้องติดตั้ง Python 3.11 หรือ 3.12 ก่อน จากโฟลเดอร์หลักของโปรเจกต์:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r backend/requirements.txt
```

เริ่ม API ใน Terminal แรก:

```sh
python -m uvicorn backend.app:app --reload --host 127.0.0.1 --port 8000
```

เริ่มหน้าเว็บใน Terminal ที่สอง:

```sh
python3 -m http.server 8080 --directory frontend --bind 127.0.0.1
```

เปิด <http://localhost:8080> โดยปล่อย Terminal ทั้งสองทำงานไว้ ตรวจ API ได้ที่ <http://localhost:8000/health> และดูเอกสาร API ได้ที่ <http://localhost:8000/docs>.

## วิธีใช้

1. เลือกรูปอาหารจากเครื่อง
2. ปรับปริมาณด้วยช่องกรัม ปุ่มเพิ่มลด หรือแถบเลื่อน
3. กด **วิเคราะห์จานนี้** ระบบจะเลือกโมเดลให้อัตโนมัติและคำนวณโภชนาการโดยประมาณ
4. ปรับปริมาณต่อได้เพื่อดูค่าที่คำนวณใหม่ทันที
5. กด **บันทึกมื้อนี้** เพื่อเพิ่มลงประวัติและดูสรุปแคลอรีกับสารอาหารย้อนหลัง 7 วัน

ประวัติอาหารเป็นรายการร่วมของโปรเจกต์ เพราะไม่มีบัญชีผู้ใช้แยกกันแล้ว ฐานข้อมูลเดิมจะถูกปรับ schema ตอนเริ่ม API โดยเก็บประวัติมื้อเดิมไว้และลบตารางบัญชีผู้ใช้เก่า

## โมเดลและข้อมูลโภชนาการ

Food-101 มี 101 คลาส ใช้ `food101_effnetb0.onnx`, `food101_effnetb0.onnx.data` และ `classes.json`; THFOOD-50 มี 50 คลาส ใช้ `thfood50_effnetb0.onnx` และ `classes_thfood50.json`. หากมีโมเดลเพียงชุดเดียว ระบบใช้ชุดที่พร้อมใช้งาน.

ตัวเลือกอัตโนมัติใช้คะแนนภายใน THFOOD-50 เป็นเกณฑ์คัดกรอง ไม่ได้เปรียบเทียบคะแนนระหว่างสองโมเดลโดยตรง เกณฑ์เริ่มต้นคือคะแนนอันดับหนึ่งอย่างน้อย 0.50 และระยะห่างจากอันดับสองอย่างน้อย 0.10; ปรับได้ด้วย `THFOOD50_AUTO_MIN_CONFIDENCE` และ `THFOOD50_AUTO_MIN_MARGIN`. ควรปรับเกณฑ์ด้วยชุด validation ที่มีทั้งอาหารไทยและอาหารสากล.

Food-101 ใช้ snapshot โภชนาการ USDA ใน `backend/model/usda_fndds_mappings.json`. THFOOD-50 ใช้ข้อมูลจากรายงาน [โครงการปริมาณสารอาหารในอาหารจานเดียวของกรมอนามัย](https://nutrition2.anamai.moph.go.th/web-upload/6x22caac0452648c8dd1f534819ba2f16c/m_document/32006/14552/file_download/b1e88d991fb8a07533dfcbe1467774a6.pdf) ใน `backend/model/thfood50_nutrition.json`. เมนูที่จับคู่ใกล้เคียงจะแสดงเป็นค่าประมาณ; โมเดลจำแนกชื่ออาหารจากภาพ แต่ไม่ได้วัดน้ำหนักจริงของอาหาร.

## แก้ปัญหาเบื้องต้น

- หากหน้าเว็บไม่ขึ้น ให้ตรวจว่า frontend ทำงานที่ port `8080`
- หาก API ไม่ตอบ ให้ตรวจว่า backend ทำงานที่ port `8000` และเปิด <http://localhost:8000/health> ได้
- หากแจ้งว่าไม่มีโมเดล ให้ตรวจไฟล์ ONNX และ class list ใน `backend/model/`; Food-101 ต้องมีไฟล์ sidecar `.onnx.data` ด้วย
- หากไม่มีข้อมูลโภชนาการสำหรับเมนูนั้น ระบบยังแสดงผลจำแนกได้ แต่ไม่แสดงสารอาหารที่ไม่มีข้อมูลรองรับ
